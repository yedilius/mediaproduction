# mediaproduction — permanent project rules

- The project is named `mediaproduction`.
- This is an existing portfolio being adapted, not a disposable new site.
- Preserve real portfolio cases, photos, videos, results, and useful components.
- Production branch is `main`.
- Use the configured GitHub `origin` and the linked Vercel `projectId`/`orgId` once created.
- Do not create additional GitHub repositories, Vercel Projects, or production domains after the initial infrastructure setup.
- Run lint, typecheck, tests, and production build before every push.
- Never push a broken build.
- Never commit `.env*`, API keys, tokens, passwords, private documents, or other secrets.
- Do not invent financial results, client metrics, legal readiness, or legal documents.
- Keep financial assumptions in explicit configuration files and label projections as plans, scenarios, or strategic potential.
- Maintain one design system: one typography scale, spacing system, card radius, color system, animation language, button style, table style, and chart style.
- Do not publish the name Edil on the public site.
- Use the public role wording: `Стратег-менеджер и инициатор проекта`.
- Do not add shooting-day timings, hourly shooting schedules, or operator schedules.
- Do not delete the existing portfolio.
- After successful logical changes, make a clear commit and push to `origin/main`.
